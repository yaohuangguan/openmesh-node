Why OpenMesh

Fast HTTP is solved.
Connected services still are not.

A normal Node service starts simple, then slowly accumulates discovery clients, retry libraries, configuration polling, tracing glue and shutdown edge cases. OpenMesh makes the common service-runtime pieces first-class without replacing Node itself.

01

Native Node HTTP, not a proxy layer

Your request handler stays on the Node.js request path. No Go sidecar. No IPC hop. No framework hidden underneath.

router→middleware→handler→response
02

Discovery that feeds routing

Register with expiring leases, watch membership changes and route calls across live peers with stable rendezvous hashing.

03

Live config without restart loops

Revisioned configuration, compare-and-swap updates and push-based SSE watches with polling fallback.

04

Failures are part of the API

Deadlines, safe retries, circuit breaking, bounded broadcast and per-peer latency / health telemetry are built in.

05

TypeScript is the source, not decoration

One strict src/**/*.ts tree emits CommonJS, ESM and public declarations. No hand-maintained type mirror.

60 second start

The small version is still small.

You do not need the control plane, mesh client or ecosystem bridges to use the HTTP runtime.

server.ts 
import openmesh from 'openmesh-node';
import { jsonBody } from 'openmesh-node/plugins';

const app = openmesh();
app.use(jsonBody());

app.get('/', () => ({ hello: 'OpenMesh' }));
app.get('/users/:id', ctx => ({ id: ctx.params.id }));

await app.listen({ port: 3000 });

Fastify relationship

No, OpenMesh does not depend on Fastify.

The native runtime has zero runtime dependencies. Fastify is an optional peer dependency used only when you explicitly call the compatibility bridge.

✓

Normal OpenMesh app
Fastify is never loaded.

✓

app.fastify(...)
Uses a real Fastify 5 instance, if you installed it.

✓

Package core
No Express, Fastify, Koa or native addon dependency.

// Native path — no Fastify involved
const app = openmesh();
app.get('/health', () => ({ ok: true }));

// Optional compatibility island
app.fastify('/legacy', async host => {
  host.get('/hello', async () => ({
    engine: 'fastify'
  }));
});
