The data path

Keep the request path boring.

Application traffic stays inside Node. The runtime handles routing, middleware, validation, response serialization and graceful shutdown without introducing a second request engine.

02 peer mesh

The service path

A peer call is more than fetch().

OpenMesh turns a changing set of service instances into a routable peer pool with stable selection, deadlines, safe retries, circuit state and transport telemetry.
