02 peer mesh

The service path

A peer call is more than fetch().

OpenMesh turns a changing set of service instances into a routable peer pool with stable selection, deadlines, safe retries, circuit state and transport telemetry.

04 protocol surface

The wire contract

A small protocol with explicit state semantics.

The control plane is an HTTP boundary, not an implementation detail. Registration, discovery and configuration can move to another storage implementation as long as these lease, revision and watch semantics stay intact.

methodpath below /_meshsemantic
POST /services/:service/instances/:id create an expiring lease
PUT /services/:service/instances/:id/lease ownership-safe lease renewal
DELETE /services/:service/instances/:id lease-scoped deregistration
GET /services/:service revisioned discovery pages
GET /watch/services/:service resumable SSE membership snapshots
GET /config/:namespace epoch + revision snapshot
PUT /config/:namespace compare-and-swap replacement
GET /watch/config/:namespace resumable SSE config snapshots
failure model What happens when the happy path stops.
caller abort

Inflight accounting is released without recording a peer failure.

unsafe write

Mutating requests are not retried implicitly by default.

stale owner

An old lease ID cannot remove or renew a replacement registration.

watch reconnect

Last-Event-ID suppresses duplicate state and converges on the current snapshot.

invalid config

The last accepted immutable snapshot remains active when validation fails.

control outage

Application traffic is separate; registrations may expire if heartbeats cannot recover.

06 operational scope

Boundary conditions

Know exactly what the runtime does not promise.

The built-in pieces are intentionally small. Production durability, platform health policy and distributed consensus stay outside the core unless an external adapter or deployment system provides them.

built-in state Process-local memory

Registry and configuration state are lost on restart. They are defaults for local clusters, tests and early deployments — not replicated storage.

consistency No hidden consensus

The runtime does not provide leader election, distributed transactions or multi-writer consensus. Durable adapters define those guarantees.

network Known HTTP peers

Peer routing operates over known service URLs. NAT traversal, overlay networking and DHT membership are outside the current model.

authorization Shared control token

The bundled control plane authenticates with a Bearer token. It does not provide RBAC, audit history or secret-management semantics.

health Lease ≠ route health

A current registration proves lease ownership, not that every application route is healthy. Keep platform health checks and traffic policy.

extensibility Adapters own the upgrade path

RegistryAdapter and ConfigAdapter let external stores preserve the public protocol without entering the application request path.

Small core

Use one layer. Or the whole runtime.

import openmesh from 'openmesh-node';
import { jsonBody } from 'openmesh-node/plugins';

const app = openmesh();
app.use(jsonBody());

  id: ctx.params.id
}));

await app.listen({ port: 3000 });
